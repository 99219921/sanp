SANPAID FRONTEND DEMO
=====================

This folder is the standalone frontend requested for the SanPaid SIH 2026 demo.

Open index.html directly in Microsoft Edge/Chrome.

Files:
- index.html  -> main frontend
- style.css   -> complete responsive UI
- app.js      -> demo interactions, cart counter and AI/voice UI
- assets/logo.png -> uploaded SanPaid logo

This version is frontend-only. Backend/database/auth/payment APIs can be connected later.
